## Sample JS Code

This repository contains sample JavaScript code for demonstration purposes.
Feel free to explore and modify the code as needed.

## for loop

```javascript
for (let i = 0; i < 2; i++) {
  console.log("Iteration number: " + i);
}
```

## if-else statement

```javascript
let number = 10;
if (number > 0) {
  console.log("The number is positive.");
} else if (number < 0) {
  console.log("The number is negative.");
} else {
  console.log("The number is zero.");
}
```
